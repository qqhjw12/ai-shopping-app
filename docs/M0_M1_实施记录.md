## 二、双模式设计（关键）

| 模式 | 触发 | 向量 | 关键词 | 嵌入 |
|------|------|------|--------|------|
| **local** | `RUN_MODE=local`（默认） | 内存（余弦） | 内存（词重叠+子串） | 本地哈希嵌入（零依赖） |
| **docker** | `RUN_MODE=docker` | Qdrant | Elasticsearch | Ollama `nomic-embed-text` |

- 任一外部服务调用失败，自动降级到内存实现并打印 warn，**服务不崩**。
- 内存兜底始终维护，保证 local 模式与异常时可用。

## 三、本地运行（无需 Docker，已验证）

```bash
cd D:\shapp\ai-gateway
export RUN_MODE=local
export EMBEDDING_PROVIDER=local
npm start            # 或 node src/server.js
# 启动即自动 seed 12 条商品

# 另开终端测试
curl -s http://127.0.0.1:8080/health
curl -s -X POST http://127.0.0.1:8080/api/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"降噪耳机","topK":3}'
```

实测结果（local 模式，3 个查询 Top1 均正确）：
- `降噪耳机` → 声海 主动降噪无线蓝牙耳机（score 0.646）
- `办公便携笔记本` → 云帆 14 轻薄笔记本电脑（score 0.59）
- `冬天保暖衣服` → 暖冬 羽绒服（score 0.581）

> 注：沙箱内 curl 需加 `--noproxy '*'` 绕过代理；本机正常环境可省略。

## 四、Docker 模式运行（你本机，需 Docker + 模型）

```bash
cd D:\shapp
cp .env.example .env          # RUN_MODE=docker, EMBEDDING_PROVIDER=ollama
docker compose up -d

# 拉取嵌入模型（首次）
docker exec shopping-ollama ollama pull nomic-embed-text
# 离线演示小模型（可选）
docker exec shopping-ollama ollama pull qwen2.5:0.5b

# 触发种子（服务启动会自动 seed；也可手动）
curl -X POST http://localhost:8080/api/seed
curl -X POST http://localhost:8080/api/search -H 'Content-Type: application/json' -d '{"query":"降噪耳机"}'
```

健康检查：
- Ollama: `curl http://localhost:11434`
- Qdrant: `curl http://localhost:6333/collections`
- ES: `curl http://localhost:9200/_cluster/health`

## 五、与 mall 的接入约定（M2+ 落地）

AI Gateway 通过 `MALL_BASE_URL` 调 mall 暴露的只读内部接口：
- `GET /api/ai/products` → 返回商品列表（字段对齐 `data/products.js`：id/name/category/brand/price/tags/description）
- mall 二次开发需新增 `mall-ai` 模块暴露上述接口，并在商品增改时事件驱动 `/api/seed` 增量同步（幂等 + 重试）。
