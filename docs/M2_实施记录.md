# M2 实施记录 · Dify 智能客服 + 商品问答 + mall-ai 集成模块

> 状态：代码已落地，本地（沙箱）冒烟通过；Docker 真实链路需在你本机（已装 Docker+JDK）跑。
> 路线：Route A 开源二次开发（macrozheng/mall 内核不动，AI 全外置）。
> 日期：2026-10-26

## 一、本阶段目标

1. **Dify 承载智能客服 + 商品问答**：两个 Dify App（客服知识库 / 商品知识库），统一经 `ai-gateway` 的 `difyClient` 调用。
2. **mall-ai 集成模块**：在 mall fork 中新增模块，暴露 `GET /api/ai/products` 与 `/{id}`，供 Gateway 回调与同步数据。

## 二、数据流

```
用户 ──▶ 前端/App ──▶ ai-gateway
                         │
          ┌──────────────┴───────────────┐
          │ 客服 / 商品问答               │ 商品同步
          ▼                               ▼
   difyClient.chat()              syncProductsToDataset()
          │                               │
          ▼                               ▼
   Dify chat-messages API          Dify Dataset API
   (客服 App / 商品问答 App)         (商品知识库，供 RAG 检索)
          │
          └─ 失败自动降级 ──▶ 本地 faq / 本地向量检索兜底

   ai-gateway ──(回调)──▶ mall-ai  GET /api/ai/products
                                （fork macrozheng/mall 新增模块）
```

## 四、双模式说明

| 模式 | 智能客服 | 商品问答 | 商品来源 |
|------|----------|----------|----------|
| `local`（默认，沙箱可跑） | `faq.js` 关键词匹配 | 本地向量混合检索 + 模板作答 | 内置 12 条样本 |
| `docker`（你本机） | Dify 客服 App | Dify 商品问答 App（RAG） | `mall-ai` 真实接口 |

切换：复制 `.env.example` 为 `.env`，设 `RUN_MODE=docker` 并填 `DIFY_CS_API_KEY` / `DIFY_PQA_API_KEY` / `DIFY_DATASET_ID` / `DIFY_DATASET_API_KEY`。

## 六、你本机怎么跑（Docker 一把梭）

```bash
cd D:\shapp
cp .env.example .env        # RUN_MODE=docker，填 DIFY_* 与 MALL_BASE_URL=http://mall:8081

# 1) 基础设施 + Gateway
docker compose up -d
docker exec shopping-ollama ollama pull nomic-embed-text

# 2) Dify 中枢
docker compose -f docker-compose.dify.yml up -d
#    浏览器开 http://localhost:3000 初始化账号，建两个 App（客服 / 商品问答），
#    在「应用 -> 访问 API」拿到 API Key 填进 .env；商品问答 App 绑定一个空知识库，记下 DATASET_ID

# 3) 拉起 mall fork（含 mall-ai 模块）
#    mvn clean install -pl mall-ai -am && 启动 mall-admin（端口 8081）

# 4) 同步商品到 Dify 知识库
cd ai-gateway && npm run sync:dify

# 5) 验证
curl -X POST http://localhost:8080/api/ai/chat -H 'Content-Type: application/json' -d '{"message":"运费多少"}'
curl -X POST http://localhost:8080/api/ai/qa   -H 'Content-Type: application/json' -d '{"query":"适合送长辈的礼物"}'
```

## 七、mall-ai 接入要点（详见 mall-ai/README.md）

1. 将 `mall-ai/` 放到 mall fork 根目录，与 `mall-admin` 同级。
2. 根 `pom.xml` `<modules>` 加 `<module>mall-ai</module>`；`mall-admin/pom.xml` 加 mall-ai 依赖。
3. 在 mall-admin 的 `SecurityConfig` 中把 `/api/ai/**` 设为 `permitAll()`。
4. 可选：配置 `ai.gateway-key` 与 Gateway 的 `AI_GATEWAY_KEY` 一致，启用内网回调鉴权。
5. `AiProductDTO` 字段与 `ai-gateway/src/data/products.js` 对齐，离线/在线数据可互换。
