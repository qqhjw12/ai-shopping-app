## 一、本阶段目标

1. **AI 导购**：对话式推荐出商品卡片（`POST /api/ai/guide`），Dify Agent 负责导购话术，卡片结构由网关检索保证结构化。
2. **前端集成**：客服浮窗、商品页「问我这件商品」入口、导购面板，统一对接 ai-gateway，含加载/错误/重试。

## 二、新增端点与数据流

```
前端 web/ ──► ai-gateway
  │            ├─ POST /api/ai/guide  → guide.js（混合检索出卡片 + Dify 导购话术）
  │            ├─ POST /api/ai/qa     → difyClient.chat(product-qa, productId 聚焦)
  │            ├─ POST /api/ai/chat   → difyClient.chat(customer-service)
  │            └─ GET  /api/products  → search.listAllProducts()
                         │
                 docker 模式：Dify 各 App（客服/问答/导购）+ mall /api/ai/products
                 local  模式：faq 兜底 + 本地向量检索 + 模板话术
```

## 四、双模式说明

| 能力 | docker 模式 | local 模式（沙箱可跑） |
|------|-------------|------------------------|
| AI 导购话术 | Dify 导购 App（Agent 可回调 mall） | 模板话术「根据您的需求…精选 N 款」 |
| 导购卡片 | 网关混合检索（Qdrant+ES 真实向量） | 网关本地哈希向量检索 |
| 预算/品类过滤 | Dify Agent 抽取 | `guide.js` 轻量文本解析（预算/品类） |
| 商品问答 | Dify 知识库 RAG（含 productId 上下文） | 本地向量检索 + productId 聚焦 |
| 客服 | Dify 客服 App | faq 关键词兜底 |

## 五、本地冒烟结果（已验证，sandbox 内）

- `GET /api/products` → 返回 12 个商品 ✓
- `POST /api/ai/guide {"message":"预算1000以内的办公耳机"}` → 正确过滤出「声海 主动降噪无线蓝牙耳机 ¥899」「声海 电竞游戏耳机 ¥459」（耳机且 ≤1000）✓
- `POST /api/ai/qa {"productId":"p003"}` → 聚焦回答「云帆 14 轻薄笔记本」详情 ✓
- `OPTIONS` 预检带 `Origin: http://localhost:5500` → 返回 `Access-Control-Allow-Origin` 等 4 个 CORS 头 ✓
- 静态前端 `python -m http.server 5500` → `index.html`/`app.js`/`styles.css` 均 HTTP 200 ✓
- 全部 JS `node --check` 通过 ✓

> 注：local 模式的哈希嵌入是廉价近似，语义召回弱于真实 Ollama 向量；预算/品类在 local 由文本解析，docker 由 Dify Agent 抽取，二者互补。

## 六、你本机怎么跑（Docker 一把梭 + 前端）

```bash
# 1) 网关 + 基础设施
cd D:\shapp && cp .env.example .env   # RUN_MODE=docker
docker compose up -d
docker exec shopping-ollama ollama pull nomic-embed-text

# 2) Dify 中枢（建 3 个 App：客服 / 商品问答 / 导购，导购 App 配外部 API 工具指向 mall /api/ai/products）
docker compose -f docker-compose.dify.yml up -d

# 3) 启动前端
cd web && python -m http.server 5500
# 浏览器开 http://localhost:5500 （若网关不在 8080，加 ?api=http://localhost:8080）
```
