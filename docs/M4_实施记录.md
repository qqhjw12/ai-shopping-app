# M4 实施记录：运营文案 + 订单售后（Dify 无代码后台）

> 日期：2026-10-26
> 关联决策（已确认）：**建 Dify 无代码后台**——运营同事直接在 Dify 控制台自助使用两个 Workflow，网关仅做转发，不写独立运营后台、不引入 n8n。
> 双模式契约：local 内置模板/样本降级可离线演示；docker 模式调用真实 Dify Workflow，失败自动回退。

## 一、本阶段交付

### 1. 网关新增两个 AI 模块端点
- `POST /api/ai/copywrite` —— 运营文案生成
  - 入参：`product{name,brand,category,price,tags}`、`sellingPoints[]`、`tone`(专业/活泼/种草/促销)、`platform`(通用/淘宝/抖音/小红书)、`count`
  - 出参：`titles[]`、`detail`、`social[]`、`hashtags[]`、`mode`
- `POST /api/ai/aftersale` —— 订单售后助手
  - 入参：`userId`、`orderId?`、`query?`
  - 出参：`answer`、`orders[]`、`mode`

### 2. 模块实现（双模式）
- `src/copywrite.js`：docker 调 `runWorkflow(copywriteApiKey)`；local 用内置多语气模板生成标题/详情/种草文案。
- `src/aftersale.js`：docker 调 `runWorkflow(aftersaleApiKey)`；local 用样本订单 + 规则给出状态/物流/退换货指引。
- `src/difyClient.js`：新增 `runWorkflow()`（POST `/v1/workflows/run`），`appEnabled` 支持 `copywrite` / `aftersale` 模式。
- `src/mallClient.js`：新增 `getOrders(userId)`、`getOrder(orderId)`（docker 调 `mall /api/ai/orders`，local 返回样本订单）。

### 3. Dify 无代码后台交付物（运营自助面）
- `dify-workflows/copywrite.spec.json`、`aftersale.spec.json`：两个 Workflow 的节点蓝图（开始变量 → LLM/HTTP → 结束输出），供运营在 Dify 控制台按图搭建/微调。
- `scripts/create-dify-workflows.js`：可选脚本，docker + `DIFY_ADMIN_KEY` 时批量建 App 壳；否则打印待办清单（已验证降级）。
- `docs/ops-runbook.md`：运营同事纯无代码使用手册（建应用、填变量、改 prompt、权限协作、排错）。

### 4. 配置
- `.env.example` 新增 `DIFY_CW_API_KEY`、`DIFY_AS_API_KEY`。
- `config.js` 的 `dify` 增加 `copywriteApiKey`、`aftersaleApiKey`。

## 二、本地冒烟（已验证，sandbox 内 local 模式）
- 文案「声海耳机 / 种草 / 小红书 / 2 条」→ 产出 2 标题 + 详情 + 2 条种草文案，`mode: local` ✓
- 售后 `userId=u1` → 命中 2 个订单（shipped/completed），物流与退货指引正确 ✓
- 售后 `userId=u2` → 1 个订单（paid，提示备货中）✓
- 售后 `userId=ghost` → 提示无订单 ✓
- 售后 `orderId=SO20260928007` → 锁定该订单 ✓
- 创建脚本 local 降级打印待办清单 ✓；`/` 端点清单含新两个端点 ✓；全部 JS 语法通过 ✓

> 修复记录：初版 `localAfterSale` 未 `await getOrders`（异步），导致按 userId 查单返回空；已改为 `async` + `await`。

## 三、你本机怎么跑（docker 模式接真实 Dify）
```bash
# 1) 在 Dify 控制台按 dify-workflows/*.spec.json 建两个 Workflow 并发布，拿到 Key
# 2) 填 .env
DIFY_CW_API_KEY=<运营文案 App Key>
DIFY_AS_API_KEY=<订单售后 App Key>
# 3) 启动
cd D:\shapp && cp .env.example .env   # RUN_MODE=docker
docker compose up -d
docker compose -f docker-compose.dify.yml up -d
# 4) 验证
curl -X POST http://localhost:8080/api/ai/copywrite -H 'Content-Type: application/json' \
  -d '{"product":{"name":"声海耳机","brand":"声海","category":"耳机","price":899},"tone":"种草","platform":"小红书"}'
curl -X POST http://localhost:8080/api/ai/aftersale -H 'Content-Type: application/json' -d '{"userId":"u1"}'
```
